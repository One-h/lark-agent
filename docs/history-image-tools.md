# 历史聊天图片工具

## 行为与边界

- 单聊、群聊的可信及非可信发送人都可在当前任务按需检索历史图片；不因此获得命令执行或跨会话读取权限。
- 普通群聊只检索普通群消息；原生话题只检索本话题及其根消息，不跨群、私聊或其他话题。
- `history_images_search` 只返回图片消息的编号、时间、发送者和文字预览，不下载图片。省略关键词可查最近图片，游标可向前翻页；关键词不识别图片中的文字。
- `history_images_open` 只接受当前消息最近一次搜索给出的候选，下载后通过 MCP image 内容块交给模型，不是只返回一个本地路径。
- 当前 turn 的并发调用及追加消息共享最多四张图片的预算。新 turn 重置预算；单张不超过 8 MB。普通历史消息不会自动注入全部图片。
- 每轮提示词携带临时上下文令牌，服务端同时校验运行时身份和当前活动消息。过期令牌、未来消息、其他会话及话题均不能打开。
- MCP 暂沿用 `lark_stickers` 服务名，但历史图片工具与表情包使用开关独立；关闭表情包不关闭历史图片读取。

## 变更与验收

此前工具已存在，但非可信群消息既不获得工具说明，也会被服务端拒绝。现在统一以当前会话/话题范围控制图片可读性，保留命令权限隔离；工具说明明确先搜索元数据、需要时再打开像素。

验收覆盖：非可信群聊且表情关闭时通过真实 MCP→运行时→下载适配器获得 image 内容块；候选与会话越界拒绝；过期令牌拒绝；并行/追加消息共享四图预算；搜索不返回像素；新 turn 重置预算。
自动测试只使用临时数据库与模拟下载。可用 `LARK_HISTORY_IMAGE_SMOKE_MESSAGE_ID` 和 `LARK_HISTORY_IMAGE_SMOKE_IMAGE_KEY` 指定一组匹配的真实资源，运行隔离数据库下载测试；不重放消息、不发送回复，也不写现有运行数据库。
