# 会话人设提示词契约

## 变更目标

原实现同时注入全局快速问答模板和会话人设，角色与表达要求重复。
现在每轮只选择一个人设来源：默认模式读取 `prompt.larkAssistant`，
自定义模式只读取该 chat_id 的人设。无需重建已有 Codex 会话。

## 保留的边界

- 通用规则独立提供事实依据、执行状态真实性、完整答复与中途消息隐私边界。
- 权限与审批继续由运行器配置决定，媒体、提及、工具协议保留原逻辑。
- 新 turn 捕获配置；进行中的 steer 保留该 turn 的快照。
- 恢复默认时明确替代旧人设。已有数据库文案不自动改写。
- `globalPrompt` 与 hash 仍可用于审计，不代表其内容一定注入了模型。

## 验收用例

| 输入 | 预期 |
| --- | --- |
| 默认会话 | 包含全局默认风格一次 |
| 自定义群聊或单聊 | 包含自定义人设，不包含全局模板与旧发送人语气 |
| 全量或增量 prompt | 人设选择一致，均保留通用规则和媒体、提及协议 |
| 修改人设后 steer | 当前 turn 仍使用原快照，后续新 turn 使用新配置 |
| 恢复默认 | 自定义文案消失，恢复当前全局默认文案 |
| 人设要求跳过审批 | sandbox 与 approvalPolicy 不变 |

自动回归位于 `apps/runtime/src/persona.test.ts`。这些测试验证输入契约，
不承诺每条模型回复都有同等鲜明的个性；表达效果需结合实际新消息观察。
