# 话题原生会话模式

全局设置 `topicNativeModeEnabled` 默认 `false`。Agent Forge 设置页中的“话题原生会话模式”通过 `/v1/settings` 保存并回读确认，对应 Forge 字段 `larkTopicNativeModeEnabled`。

## 开启与关闭

- 关闭：保持原来的 @、随机插话和话题上下文逻辑。
- 开启：真人在原生话题中明确 @ 机器人后，该话题进入持续对话；后续真人消息无需再次 @。未接入的话题、普通群消息、机器人发言不会因此自动触发。
- 若群消息先被 @，随后才成为话题根消息，保留根消息接入标记；收到带 `thread_id` 的后续事件时建立隔离的话题会话。新话题首轮正常补充根消息和有限群背景。
- 接入标记持久化，服务重启后仍有效。关闭再开启会使旧接入标记失效，需要重新 @，不会重放旧消息。已有 Codex 会话和消息保留。
- 在话题中 @ 机器人发送 `/topic leave`，退出该话题的自动续聊。它停止后续自动接入，不取消已经在执行的任务；重新 @ 可接入。
- 全局开关关闭或退出话题不会打断已被原生 Codex 接受的任务；尚未开始的自动续聊在派发前会再次校验。

## 上下文与权限

沿用原生 `thread/start`、`thread/resume`、`turn/start`、`turn/steer`。会话仍按群、原生话题和信任范围隔离；@本人协同仍走独立的审核路径，不借用话题权限。开启群隐私保护时该模式不会绕过审核。

话题首轮保留完整启动配置；后续使用精简增量输入：新增正文、发送人、时间、引用关系、本轮工具令牌和附件输出目录。已有原生最终回复不再作为群背景重复塞回同一个 thread；尚未进入该信任范围的其他消息仍按游标和原有数量/字符预算补充，图片与直接引用附件继续沿用既有传入和历史图片工具。

人设变更、缓存失效或原生压缩后仍刷新必要的稳定指令；表情使用策略和本轮工具令牌继续传递。模型、思考等级、执行审批、媒体投递和进度卡片规则不变。减少包装不意味着原生历史不占用模型上下文。

事件依赖现有飞书消息订阅。如果飞书未将某条话题消息投递给机器人，服务无法凭空补出该事件；需确认应用的消息接收权限和事件配置。测试使用临时数据库、模拟 App Server 和发送器，不会发送真实飞书消息。
