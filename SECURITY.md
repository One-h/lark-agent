# Security Policy

Lark Agent runs tools and may access credentials on the deploying user's
computer. Do not publish tokens, contact directories, chat histories, approval
payloads or working exploit details in public issues.

Report vulnerabilities privately through the repository's GitHub Security tab.
Include the affected version, a minimal reproduction with synthetic data,
impact and suggested mitigation. If private reporting is unavailable, request
a private contact channel without disclosing exploit details.
